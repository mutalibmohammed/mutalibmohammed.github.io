# mutalibmohammed.github.io

**Zone 1 Pub Crawl** — one button, one map, one pint. A TfL-Go-style schematic
map of central London with the best-reviewed pub named under each of 37 Zone 1
stations. Tap *Pick a pub* and go.

Live at **https://mutalibmohammed.github.io/**

- `index.html` / `styles.css` / `app.js` / `data.js` — the app (static, no dependencies)
- `data.js` — the pub roster and map geometry; edit here to swap pubs
- `DESIGN.md` — the design sketch the app was built from
- `/valentine/` — the previous front page, preserved

Unofficial fan project — not affiliated with TfL. Drink responsibly.
